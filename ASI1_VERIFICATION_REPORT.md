### 2. Code Path Analysis

The evaluation route at `packages/backend/src/routes/evaluations.ts:124-137` determines which evaluator to use:

```typescript
const apiKey = c.env.ASI1_API_KEY;
const model = c.env.ASI1_MODEL || DEFAULT_ASI1_MODEL;  // "asi1-mini"
const useRealEvaluator = !!apiKey;

if (useRealEvaluator) {
  evaluationData = await evaluateProject(apiKey, model, { ... });
} else {
  evaluationData = generateMockEvaluation({ ... });
}
```

Since `ASI1_API_KEY` is set as a secret, `!!apiKey` is `true`, so `evaluateProject()` (the real ASI1 evaluator) is called, **not** `generateMockEvaluation()`.
